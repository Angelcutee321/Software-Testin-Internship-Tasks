Task 4 – Load Testing using Gatling

Description

This task focuses on performing load testing on a web application using Gatling. The purpose of this task is to evaluate the system performance when multiple users access the application simultaneously.

Objective

- Simulate multiple virtual users accessing the application.
- Measure response time and system performance.
- Identify possible performance issues under heavy load.

Tools Used

- Gatling
- Scala
- Web Browser

Files Included

- Gatling Load Testing Script (LoginLoadTestSimulation.scala)
- Load Testing Report (Task4_Load_Testing_Report_Gatling.docx)

Conclusion

The load testing simulation helps analyze how the application behaves under user traffic and ensures that the system performs efficiently under load conditions.
